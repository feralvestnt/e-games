PURPOSE
This V2 is a more detailed compatibility-first game character with semantic mesh names,
separate shield/sword props, and an explicit humanoid rig + animation specification.

IMPORTANT
The GLB itself is not pre-rigged or pre-animated. The included specification is designed
for Cinevva's rigging/animation step (or another humanoid auto-rigger). This avoids
pretending that procedural geometry already contains a production-quality skeleton.

HISTORICAL NOTE
This is a recognizable Templar-inspired game character, not a strict archaeological
reconstruction of one exact year. The great helm, mail, white surcoat and red cross are
intended for a High Medieval visual language.
