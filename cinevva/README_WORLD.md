# Castalla 1244 — Cinevva package

All GLBs share one world coordinate system. Load each at position [0,0,0], rotation [0,0,0], scale [1,1,1].

Historical confidence:
- Castle: historically informed game reconstruction from the official plan and published archaeology.
- Village: approximate; sources place the Andalusi population nucleus on the south/east slopes, but do not establish a complete house-by-house 1244 plan.
- Roads: approximate gameplay paths.
- Props: generic period-compatible placeholders.

Target year: circa 1244.
Do not add the later 14th–15th century Palau form or Torre Grossa (1529).
Do not reposition assets independently.
