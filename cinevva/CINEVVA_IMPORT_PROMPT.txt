Use the supplied Castalla terrain package as an authoritative geographic reference.

Read `README_WORLD.md` and `world.json` before changing the scene.

Import `Castalla_Hill_Reference_Yup.glb` at:
- position: [0, 0, 0]
- rotation: [0, 0, 0]
- scale: [1, 1, 1]

The model uses meters, Y-up, X positive east, Z positive north.

IMPORTANT:
- Do not generate a castle yet.
- Do not generate a village yet.
- Do not flatten, reshape, rotate or rescale the terrain.
- Do not invent historical structures.
- Keep the terrain as a separate reusable asset.
- Treat `world.json` as authoritative scene metadata.

For this first step, only create a clean playable inspection scene around the supplied terrain:
1. neutral daylight,
2. a sky/environment,
3. a controllable inspection camera or player,
4. conservative Mediterranean ground/rock materials if they can be applied non-destructively,
5. no permanent vegetation or roads unless explicitly requested later.

The future historical castle and village will be provided as separate registered GLB assets that share the same coordinate system.
